# Cave Spelunking

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_468643_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/468643.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Cave Spelunking is a lightweight Minecraft mod which adjusts ore generation:
- Change ores to spawn only in caves
- Adjust the global spawn rate of ores
- Change how much ore is allowed to generate outside of caves

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
